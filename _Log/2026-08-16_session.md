# 2026-08-16 — Harness v4 Rebuild

Not a learning session — a full rebuild of the agent harness (`.claude/` + guards
+ protocols), driven by `/harness-audit` and evidence rather than intent.

## What was done

1. **Bash guard → tokenizing parser** (`scripts/claude/guard_bash.py`, new). The
   v3 substring guard leaked 21/44 adversarial bypasses and false-positived on
   `-n` inside a quoted message. New engine tokenizes: handles `git -C`/`-c`,
   `sh -c`/`eval`/`xargs`/`find -exec`, env-prefix, `$(…)`, `$VAR`, newlines,
   heredocs, interpreters. Decisions: block / ask / allow.
2. **pre-commit** now scans every staged *text* file (was 4 extensions),
   NUL-delimited (filenames with spaces no longer skip the scan).
3. **State sentinel** (`guard_index.sh`, new PostToolUse): unstages any
   no-publish path that reaches the index by *any* route.
4. **Write guard** (`guard_write.py`, new): credential + placement/naming checks.
5. **Structure & memory protocol** (`_System/Vault_Structure.md`, new): four
   stores, routing, when-a-folder-may-be-created, pruning cadence, agent-memory
   policy. Plus `_Log/_Parking_Lot.md`.
6. **Skills consolidated to observed usage** (transcript mining showed
   `/deep,/tool,/quick,/push` never fired): `/level` (paste-driven), `/eol`
   (Korean triggers), `/commit` (draft-only), `/init-wargame`. Dead ones demoted
   to non-firing aliases.
7. **Privacy fix**: personal email removed from committed `setup.sh`/`setup.ps1`.
8. **CLAUDE.md → v4**: every §1 claim mapped to a mechanism or labelled
   prompt-only.

## Verification (the honest part)

- **7 adversarial red-team rounds** (3 multi-agent workflows), fresh-context
  subagents attacking throwaway sandbox copies through the LIVE hook. They quoted
  the guard's exact `BLOCKED by vault policy` text → subagent-level enforcement
  is real, not a script self-test.
- **Core invariants held every round**: no unsigned/hook-skipping commit, no
  pwn.college publish, no password leak — enforced by parser + state sentinel +
  content scan + settings deny/ask + JY-runs-commits, layered.
- ~80 edge vectors found and closed (guard self-protection, git config/env
  transports, key-reads, content-laundering). **453 regression checks, green.**

## Struggle points / honest notes

- The self-introduced `$(echo …)` substitution flaw (round 5) is a reminder:
  every "clever" normalization can open a hole. Regression tests caught it.
- Guard *self-protection* is a denylist over an infinite command space — it
  cannot be proven complete. Documented in CLAUDE.md; the real backstop is
  settings-ask on guard-file edits + session-guard self-heal, not the parser.
- Stopped the red-team loop at round 7 by JY's call (correct — diminishing
  returns; only exotic config/env variants remained).
